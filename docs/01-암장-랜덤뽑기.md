# 실행계획 01 — 암장 랜덤뽑기

## 1. 개요
지역 권역을 고르고 슬롯머신 레버를 당기면 해당 권역의 실내 볼더링 클라이밍센터 이름이 빠르게 돌다가 서서히 멈추며 오늘 갈 암장을 정해주는 기능. 결과는 스냅샷 이미지와 공유 URL로 공유할 수 있고, 공유받은 사람은 "나도 돌리기"로 같은 경험을 이어간다.

## 2. 요구사항
| # | 요구사항 | 비고 |
|---|---|---|
| R1 | 권역 선택: 서울권 / 서울 외 수도권 / 수도권 외 | 실내 볼더링 센터만 대상 |
| R2 | 슬롯머신 UI: 레버를 내리면 센터명 텍스트가 회전하며 서서히 감속 후 정지 | 결과는 정지 전에 확정(서버/클라 난수) |
| R3 | 결과 스냅샷 생성 + 공유 버튼으로 결과 화면 URL 복사 | |
| R4 | "다시 돌리기", "공유하기" 버튼 | 결과 화면 하단 |
| R5 | 공유 URL 진입 시 "나도 돌리기" 버튼 표시 → 클릭 시 1번 화면(권역 선택·슬롯)으로 이동 | |

## 3. 화면/라우트
| 경로 | 설명 |
|---|---|
| `/gym-roulette` | 권역 선택 + 슬롯머신 + 결과/버튼 (R1, R2, R4) |
| `/gym-roulette/r/[id]` | 공유용 결과 페이지(읽기 전용) + "나도 돌리기" (R3, R5) |
| `/gym-roulette/r/[id]/opengraph-image` | 결과 스냅샷(OG 이미지) 동적 생성 |

## 4. 데이터
- **암장 목록**: `src/lib/gyms.ts` 정적 데이터로 시작 (`{ id, name, region: 'seoul' | 'metro' | 'etc', area, address? }`). 이후 Supabase 테이블로 이전 가능.
- **공유 결과 식별자**: 두 가지 중 택일
  - A안(권장, DB 불필요): URL에 `gymId`와 권역을 인코딩 — `/gym-roulette/r/seoul-theclimb-gangnam`. 서버 저장 없이 단순.
  - B안: `gym_roulette_results` 테이블(id, gym_id, created_at)에 저장 후 짧은 id 발급. 통계가 필요할 때만.
- 사전에 데이터 정확성(폐업·신규 센터)을 확인할 수 있도록 목록 검수 단계를 둔다.

## 5. 구현 단계
### 단계 1 — 데이터·기본 페이지
1. `docs/` 폴더 및 본 문서 작성 (완료)
2. `src/lib/gyms.ts`: 권역별 암장 목록(권역당 최소 10곳 이상) 작성
3. `/gym-roulette` 페이지 골격 + 권역 3택 토글(`toggle-group` 재사용)

### 단계 2 — 슬롯머신 컴포넌트 (`SlotMachine.tsx`)
1. 레버 UI: 드래그 또는 클릭으로 아래로 내려가는 애니메이션(키보드·버튼 접근성 대체 제공)
2. 릴: 권역 목록을 세로로 반복 나열한 스트립을 `requestAnimationFrame`/CSS transform으로 회전
3. 감속: 당첨 인덱스를 먼저 `Math.random()`으로 확정 → easeOutCubic으로 3~4초에 걸쳐 해당 항목에서 정지
4. 상태: `idle → spinning → stopped`, 회전 중 권역 변경·재클릭 비활성화
5. `prefers-reduced-motion`이면 애니메이션 단축

### 단계 3 — 결과·공유
1. 정지 후 결과 카드(센터명·지역) 표시 + "다시 돌리기"·"공유하기" 버튼
2. 공유하기: 결과 URL을 `navigator.clipboard`로 복사(기존 `lib/clipboard.ts` 활용) + 토스트 안내, 모바일은 `navigator.share` 우선 시도
3. 스냅샷: `opengraph-image` 라우트(`next/og` ImageResponse)로 센터명이 들어간 이미지를 서버에서 생성 → 링크 미리보기에 표시. 필요 시 "이미지 저장" 버튼 추가 검토

### 단계 4 — 공유 페이지
1. `/gym-roulette/r/[id]`: 결과 센터를 정적으로 표시, `generateMetadata`로 OG 메타 설정
2. "나도 돌리기" 버튼 → `/gym-roulette` 이동 (R5)
3. 잘못된 id는 `notFound()` 처리

### 단계 5 — 마무리
- 모바일 우선 레이아웃 확인, 로그인 없이 접근 가능하도록 `proxy.ts` 공개 경로에 `/gym-roulette` 추가
- 메인 메뉴(MenuCard)에 진입점 추가
- QA 체크리스트: 권역별 결과 일치 / 연속 뽑기 / 공유 URL 복사 / 공유 링크 미리보기 / 비로그인 접근 / reduced-motion

## 6. 리스크·확인 필요
- Next.js 버전이 일반 지식과 다를 수 있으므로 구현 전 `AGENTS.md`와 `node_modules/next/dist/docs` 확인
- 암장 목록 출처 및 최신성(수작업 검수 필요)
- 스냅샷은 OG 이미지 방식(서버 생성)이 안정적이며, 클라이언트 캡처(html2canvas)는 폰트·성능 이슈로 비권장
- 같은 암장이 연속 당첨되는 것을 허용할지(기본: 허용)

## 7. 완료 기준
권역 선택 → 레버 → 감속 정지 → 결과 표시 → 공유 URL 복사 → 공유 URL에서 "나도 돌리기"로 1번 화면 복귀까지 모바일/데스크톱에서 동작.
